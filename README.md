## Збирання

Код вправ використовує стандартні бібліотеки C#. Для локального збирання всіх класів можна використати .NET 8 SDK або новішу версію:

```sh
dotnet build ExercismSolutions.csproj
```

Це бібліотека класів, а не консольна програма. Перевірка кожної вправи здійснюється тестами Exercism.
